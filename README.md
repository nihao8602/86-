# 漫画翻译引擎（Manga Translate）

> 网页漫画实时翻译：识别原文 → 翻成中文 → 在原气泡位置覆盖显示。
> Tampermonkey 用户脚本，电脑和手机都能用。

作者：百事比可口好喝 · 当前版本 **7.44.0**

## 特性

- 🖼️ **气泡级识别**：同一气泡的多行合成一句，不拆碎片；拟声词 / 特效字自动跳过
- 🌐 **五家翻译引擎**：DeepSeek / 智谱 GLM / 腾讯混元 / 硅基流动 / 本地 Ollama
- 🔤 **两种 OCR**：内置免部署（浏览器直跑，支持**英 / 日 / 韩 / 简中 / 繁中 / 英日混合**，语言包按需下载）/ 本地 PaddleOCR（识别更准）
- 🎨 **三种擦除**：像素滤波（快）/ 主色填充（彩色气泡）/ LaMa 模型擦除（质量最好）
- 📐 **漫画排版**：中英混排断行、避标点行首、字号自适应、可选整图重绘
- 📱 **双端共用**：手机连电脑的 OCR 服务，局域网即可，不必两条链路各装一遍

## 30 秒上手

1. 装 [Tampermonkey](https://www.tampermonkey.net/)，导入 [`manga-translate.user.js`](https://raw.githubusercontent.com/nihao8602/86-/main/manga-translate.user.js)
2. 打开漫画页 → 右下角出现「译」悬浮球
3. 面板「翻译」页填 API Key，任选一家服务商

> 默认使用**内置 OCR**，不需要装 Python、不需要起任何服务。

> iPhone / iPad：优先用 **Safari + Tampermonkey（油猴）**。不保证所有浏览器和脚本管理器都能用，失败就换个组合再试。

## 三种用法

| 方案 | 需要装什么 | 适合 |
|---|---|---|
| 内置 OCR + 云端翻译 | **无需另外部署，浏览器直接用**（只装油猴脚本） | 想立刻用；英文漫画；日韩漫画也能用，只是准确率低一档 |
| 本地 OCR + 云端翻译 | Python 环境（约 3–4 GB），本机起个 8000 端口的识别服务 | 日漫 / 韩漫，追求识别质量 |
| 本地 OCR + 本地 Ollama | 上面那套 + 自己装 Ollama | 完全离线，零 API 费用 |

## 常见问题

**OCR 用内置还是本地？**

内置和本地都支持英 / 日 / 韩。差别在准确率：

- **英文**：两者接近，内置够用
- **日文 / 韩文**：内置能用，但小字、特殊字体容易读错；追求质量上本地 PaddleOCR
- **中文 / 繁中**：内置有语言包，本地 PaddleOCR 更稳

不想装 Python 就先试内置，觉得识别不准再上本地。

**密钥存在哪？**
只存浏览器本地（`GM_setValue`），仓库和服务器都没有。

**版本号为什么和本地不一致？**
两套编号：GitHub 走发布序列（7.4x），本机开发副本走内部编号（7.52.x）。内容逐字节相同，只差 `@version` 一行。
